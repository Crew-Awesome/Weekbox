V-Slice is the official *Friday Night Funkin'* codebase maintained by Funkin' Crew. It contains the base game, the chart editor, and the Polymod-based modding system used by the modern V-Slice releases.

## Highlights

- **Polymod modding** with structured mod metadata and asset replacement.
- The official chart editor and base-game weeks.
- A modern HaxeFlixel codebase shared by the core game and mods.
- Support for custom songs, characters, stages, and UI through mod packages.
- The reference implementation for V-Slice features and content.

## Notes

- Official desktop builds are distributed through Funkin' Crew's own channels; GitHub releases may not include binaries for every platform.
- WeekBox lists only the assets that are compatible with your operating system.
- V-Slice mods are packaged differently from Psych mods, so the two formats are not interchangeable.

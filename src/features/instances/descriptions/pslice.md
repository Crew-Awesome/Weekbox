P-Slice (Psych-Slice) is a community fork of Psych Engine that brings V-Slice-inspired mechanics, state management, and visual polish to the Psych scripting ecosystem.

## Highlights

- V-Slice-inspired presentation and interface flow.
- Reworked state and song management while staying close to Psych.
- Support for the familiar Psych Lua and HScript modding workflow.
- Visual effects and quality-of-life improvements over the base engine.
- Actively maintained by the Psych-Slice community.

## Mod structure

Because P-Slice is built on Psych Engine, most mods follow the same folder layout: `data`, `images`, `songs`, `scripts`, and `weeks` inside the mod directory. Existing Psych content is usually a good starting point, though version-specific scripts may need updates.

## Notes

- WeekBox only offers release assets published for your operating system.
- Check whether a mod was built for P-Slice specifically; some Psych mods depend on features that differ in this fork.
- Keep a backup of your mods before upgrading between major versions.

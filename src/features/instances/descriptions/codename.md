Codename Engine is a modern *Friday Night Funkin'* engine built from scratch on HaxeFlixel. It targets heavy softcoding: most gameplay, menus, and states can be extended with scripts instead of compiling a custom build.

## Highlights

- **HScript-based scripting** for states, songs, and interface elements.
- A modular state system designed for custom menus and game modes.
- HaxeFlixel rendering and input pipeline.
- Support for custom note types, events, and stage logic.
- A project layout that keeps engine code and mod content separated.

## Mod structure

Codename mods usually live in their own folder and can include scripts, assets, and custom states. Because the engine is script-oriented, a mod can replace large parts of the experience without a separate executable.

## Notes

- WeekBox only offers release assets published for your operating system.
- Some mods target a specific Codename version; check the mod's requirements before switching.
- Custom scripts may need small adjustments between major engine releases.

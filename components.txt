## Botones y Acciones (Buttons & Actions)
--------------------------------------------------------------------------------
• <m3e-button>
  Descripción: A button users interact with to perform an action.
  Atributos principales: disabled, disabled-interactive, download, href, name, rel, selected, shape, size, target, toggle, type, value, variant

• <m3e-button-group>
  Descripción: Organizes buttons and adds interactions between them.
  Atributos principales: multi, size, variant

• <m3e-icon-button>
  Descripción: An icon button users interact with to perform a supplementary action.
  Atributos principales: disabled, disabled-interactive, download, href, name, rel, selected, shape, size, target, toggle, type, value, variant, width

• <m3e-fab>
  Descripción: A floating action button (FAB) used to present important actions.
  Atributos principales: disabled, disabled-interactive, download, extended, href, lowered, name, rel, size, target, type, value, variant

• <m3e-fab-menu>
  Descripción: A menu, opened from a floating action button (FAB), used to display multiple related actions.
  Atributos principales: variant

• <m3e-fab-menu-item>
  Descripción: An item of a floating action button (FAB) menu.
  Atributos principales: disabled, download, href, rel, target

• <m3e-fab-menu-trigger>
  Descripción: An element, nested within a clickable element, used to open a floating action button (FAB) menu.
  Atributos principales: for

• <m3e-split-button>
  Descripción: A button used to show an action with a menu of related actions.
  Atributos principales: variant, size

• <m3e-segmented-button>
  Descripción: A button that allows a user to select from a limited set of options.
  Atributos principales: disabled, hide-selection-indicator, multi, name

• <m3e-button-segment>
  Descripción: A option that can be selected within a segmented button.
  Atributos principales: checked, disabled, value
